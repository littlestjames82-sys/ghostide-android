👻 GhostIDE - Help

GhostIDE is a fully offline AI code editor. The editor, your files, and a real AI model (Qwen2.5-Coder 1.5B) all live on this phone. Nothing you type is sent anywhere.

Getting around

Files are listed at the top. Tap one to open it. The editor is in the middle, the AI chat at the bottom. Your files live in the app's private storage and persist between launches.

Autocomplete

Pause while typing code. After a second or so a grey suggestion appears - tap Tab on the keyboard... on a phone keyboard, accepting works best with a keyboard that has a Tab key, or just ignore the suggestion and keep typing to dismiss it. Suggestions come from the model's fill-in-the-middle ability.

Chat

Ask about the open file (it is sent to the model as context), request functions, explanations, or fixes. Code blocks get an Insert at cursor button.

Speed

On-device AI is slower than a PC - replies stream in over a few seconds to a minute depending on length and your phone. The 1.5B model was chosen so it runs on most phones; the PC version of GhostIDE uses the bigger 7B model.

Model

Menu (⋮) -> Model shows the model's status and lets you delete it (frees 940 MB). Next launch will offer the one-time download again. The download resumes if interrupted.
